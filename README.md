# RA2 — Support / 技术支持

RA2 is a native ARM64 classic real-time strategy engine interpreter and launcher for iPad, iPhone, and Mac with Apple silicon. This repository is the public support channel for the App Store release.

- **Report a problem / ask a question:** open an [issue](../../issues/new). Please include your device model, iPadOS/iOS version, the app version (`0.1.3`), and what you were doing.
- **Privacy policy:** [PRIVACY.md](./PRIVACY.md) — RA2 collects no user data, requires no account, and contains no analytics or tracking.

---

RA2 适用于 iPad、iPhone 与搭载 Apple 芯片的 Mac，是一款原生 ARM64 经典即时战略引擎解释器与启动器。本仓库是 App Store 版本的公开技术支持渠道。

- **问题反馈 / 咨询：** 请新建一个 [Issue](../../issues/new)，并注明设备型号、系统版本、应用版本号（`0.1.3`）以及复现步骤。
- **隐私政策：** [PRIVACY.md](./PRIVACY.md) — RA2 不收集任何个人数据，无需注册账号，不含任何广告、分析或追踪代码。
